# Obsidian Prism VS Code 主题移植规划

创建/修改日期：2026-11-21。任务记录：[issue #1](https://github.com/bahayonghang/obsidian-prism-vscode-theme/issues/1)。

## 目标

将 RMvdesi / Obsidian Prism 的四套配色和主题设置做成可安装的 VS Code 扩展。只迁移外观相关内容，并清楚标明原生主题、面板视觉和显式修改全局编辑器设置的区别。

## 基准与技术选择

- 上游版本：`v1.0.7-beta.1`，提交 `5dac53bfa7cf917d40101dad2579f32dd1b1b587`。
- 许可：保留上游 GPL-3.0-only 和全部声明，注明独立移植与修改日期。
- 平台：VS Code `^1.96.0`，四个静态主题 + 桌面/浏览器扩展入口。
- 原生功能：主题、强调色、对比度、代码样式、可恢复的字体选项和系统明暗跟随。
- 面板功能：中文/英文、圆角/光效/动效预览、设置导入导出。
- 排除：额度、翻译、模型、聊天、宠物、浏览器、文件查看器，以及宿主注入、安装目录修改和守护进程。

## 实施步骤与完成条件

| 阶段 | 工作 | 完成条件 |
| --- | --- | --- |
| 1. 源码调研 | 本地克隆两仓库，固定上游版本，梳理主题与设置 | 有来源声明和逐项移植矩阵 |
| 2. 建立规划 | 创建 GitHub issue，提交可维护的规划文档 | issue 与仓库文档相互链接 |
| 3. 原生主题 | 构建四套颜色 JSON、TextMate/语义高亮和终端色表 | 静态主题完整，生成结果可复现 |
| 4. 设置逻辑 | 参数验证、主题限定的自定义、修改归属记录、恢复 | 保留其他设置及后续手工编辑；无需运行外部进程 |
| 5. Theme Studio | 中英面板、配色选择、预览、面板动效、导入导出 | 作用范围明确，消息输入经过校验，支持键盘操作 |
| 6. 可选原生设置 | 字体/连字/光标/滚动与系统明暗的显式应用、恢复 | 不在安装时自动更改用户设置；持久化影响说明清楚 |
| 7. 测试与包装 | 运行测试、构建 VSIX、检查包内容；可用时做宿主验证 | 记录实际运行结果和未能运行的检查，不能将模拟测试当作宿主测试 |
| 8. 提交与收尾 | 提交并推送完整实现，回填 issue 证据并关闭 | 远端可获取源代码与复现步骤，issue 状态已完成 |

## 回归检查清单

- 安装不会自动切换主题，静态主题无需扩展运行即可使用。
- 四套色表、命令、设置与构建产物声明一致。
- 自定义设置使用精确 Prism 主题范围；切换其他主题不受配色影响。
- 原值、无值、已有对象、数组、后续手工修改及重复应用/恢复均安全处理。
- 用户级写入不混入工作区合并结果；设置事件不导致循环写入。
- 非法/未知导入字段和值被拒绝。
- 字体与系统明暗提供独立恢复命令；Reset Prism 是包含配色和全部偏好的完整重置，不依赖卸载回调。
- 主题 JSON、桌面/浏览器 bundle、本地资源和许可证均包含在可安装包内。
- 实际宿主测试与尚未执行的验证分别记录。

## 证据记录约定

此文档定义实施与验收要求，不作为测试通过的证明。测试命令、实际结果、构建包信息、最终提交和完成状态集中记录在 [issue #1](https://github.com/bahayonghang/obsidian-prism-vscode-theme/issues/1)，以便保持一处权威记录。后续提交应继续更新必要的范围或兼容性说明。
