# Obsidian Prism VS Code 主题移植规划

创建/修改日期：2026-11-21。任务记录：[issue #1](https://github.com/bahayonghang/obsidian-prism-vscode-theme/issues/1)。

## 目标

将 RMvdesi / Obsidian Prism 的四套配色和主题设置做成可安装的 VS Code 扩展。只迁移外观相关内容，并清楚标明原生主题、面板视觉和显式修改全局编辑器设置的区别。

## 基准与技术选择

- 上游版本：`v1.0.7-beta.1`，提交 `5dac53bfa7cf917d40101dad2579f32dd1b1b587`。
- 许可：保留上游 GPL-3.0-only 和全部声明，注明独立移植与修改日期。
- 平台：VS Code `^1.96.0`，四个静态主题 + 桌面/浏览器扩展入口。
- 原生功能：主题、强调色、对比度、代码样式、可恢复的字体选项和系统明暗跟随。
- 面板功能：中文/英文、圆角/光效/动效预览、设置导入导出。
- 排除：额度、翻译、模型控制、聊天管理、宠物、浏览器、文件查看器，以及宿主注入、安装目录修改和守护进程。

## 实施步骤与完成条件

| 阶段 | 工作 | 完成条件 |
| --- | --- | --- |
| 1. 源码调研 | 本地克隆两仓库，固定上游版本，梳理主题与设置 | 有来源声明和逐项移植矩阵 |
| 2. 建立规划 | 创建 GitHub issue，提交可维护的规划文档 | issue 与仓库文档相互链接 |
| 3. 原生主题 | 构建四套颜色 JSON、TextMate/语义高亮和终端色表 | 静态主题完整，生成结果可复现 |
| 4. 设置逻辑 | 参数验证、主题限定的自定义、修改归属记录、恢复 | 保留其他设置及后续手工编辑；无需运行外部进程 |
| 5. Theme Studio | 中英面板、配色选择、预览、面板动效、导入导出 | 作用范围明确，消息输入经过校验，支持键盘操作 |
| 6. 可选原生设置 | 字体/连字/光标/滚动与系统明暗的显式应用、恢复 | 不在安装时自动更改用户设置；持久化影响说明清楚 |

| 8. 提交与收尾 | 提交并推送完整实现，回填 issue 证据并关闭 | 远端可获取源代码与复现步骤，issue 状态已完成 |

## 回归检查清单

- 安装不会自动切换主题，静态主题无需扩展运行即可使用。
- 四套色表、命令、设置与构建产物声明一致。
- 自定义设置使用精确 Prism 主题范围；切换其他主题不受配色影响。
- 原值、无值、已有对象、数组、后续手工修改及重复应用/恢复均安全处理。
- 用户级写入不混入工作区合并结果；设置事件不导致循环写入。
- 非法/未知导入字段和值被拒绝。
- 字体与系统明暗提供独立恢复命令；Reset Prism 是包含配色和全部偏好的完整重置，不依赖卸载回调。
- 主题 JSON、桌面/浏览器 bundle、本地资源和许可证均包含在可安装包内。
- 实际宿主测试与尚未执行的验证分别记录。

## 证据记录约定

此文档定义实施与验收要求，不作为测试通过的证明。测试命令、实际结果、构建包信息、最终提交和完成状态集中记录在 [issue #1](https://github.com/bahayonghang/obsidian-prism-vscode-theme/issues/1)，以便保持一处权威记录。后续提交应继续更新必要的范围或兼容性说明。

## 0.2.0：Antigravity IDE 优先适配

新的任务记录：[issue #2](https://github.com/bahayonghang/obsidian-prism-vscode-theme/issues/2)。本轮根据用户明确的主要宿主与截图补充范围，初版 #1 保持历史记录。

| 阶段 | 交付 | 验收依据 |
| --- | --- | --- |
| 官方样本调研 | IDE 1.23.2 / 2.8.0、Google 桥接与现代前端的版本/哈希/消费映射 | [ANTIGRAVITY.md](ANTIGRAVITY.md) 与证据 JSON |
| 原生侧栏适配 | 分层/统一/淡强调色、跨表面可读性、实际输入框派生模型 | 颜色模型测试，不虚构 `agy.*` 或 `chat.*` 接口 |
| 设置与预览 | 对话配色示意/编辑器切换，中英范围说明 | Chromium 交互、草稿、窄窗口与语义色计算检查 |
| 宿主信息 | 产品版本与引擎版本分开、只读报告 | 元数据测试与真实宿主报告检查 |
| 恢复回归 | 四套主题、全局/其他主题隔离、原值与手动更改保留、写入失败及旧存储通知延迟回传 | 隔离 Extension Host 场景与可确定复现的时序测试 |
| 宿主与打包 | 官方固定 IDE 包的源码检查、真实 IDE API 测试、0.2.0 VSIX | CI 与 issue #2 的最终结果 |

已核实的关键限制：新版聊天输入框通过侧栏底色派生，旧版通过编辑器底色混合灰色；两者都没有可用的独立 `input.border` 控制。普通输入边框设置仅作用于原生控件。圆角、首页布局、固定图形/边线仍由宿主控制。自动测试不需要 Google 登录，故不宣称完成用户会话的截图验收。

## 0.3.0：真实聊天材质与设置语言

日期：2026-11-22。任务：[issue #3](https://github.com/bahayonghang/obsidian-prism-vscode-theme/issues/3)、[issue #4](https://github.com/bahayonghang/obsidian-prism-vscode-theme/issues/4)。本轮明确扩展了最初“仅原生 API”的实现边界；旧阶段的排除项保留为历史决策，不当作用户禁止本地外观适配的要求。

| 阶段 | 实施内容 | 验收条件 |
| --- | --- | --- |
| 实际入口调研 | 官方 frame、CSP、旧/新客户端、模型菜单 portal | 不把外层 Webview CSS 当作内层聊天样式，不启用内部权限开关 |
| 纯样式生成 | 四套配色、极光/纹理、输入框、模型胶囊/菜单 | 仅外观，保留交互、布局和 native 图标；尊重减少动态效果 |
| 桌面适配器 | 明确开启、版本/哈希、原始备份、更新与恢复 | 不在保存/导入/启动时安装，不覆盖外部修改，不对未知文件写入 |
| 运行时集成 | 桌面与浏览器分离、5项偏好、3个适配命令 | 默认仍为原生主题；非 Prism 主题移除自己的 CSS |
| 设置语言 | 双语原生描述/枚举、独立语言命令、立即保存 | 保持配置键与原值兼容；不宣称可以独立改写原生行标题 |
| 分层验证 | 单元、真实 Electron frame、真实 IDE、Chromium | 清楚区分 fixture、官方程序启动与登录会话，不伪造视觉验收 |
| 交付 | 0.3.0 VSIX、源码、文档、issue 验证回填 | CI完成，提交可取，完成后关闭 issue |

结构、恢复路径、已审计指纹和限制见 [CHAT_APPEARANCE.md](CHAT_APPEARANCE.md)。
